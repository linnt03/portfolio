DESIGN INTERNSHIP HOS MARKETER

Figma - Capcut - AI bildegenerering - Claude Cowork for effektivisering

Designarbeidet:

Som designintern i Marketer.com produserte jeg 300–400 annonser i uken for ulike merkevarer og målgrupper. Jeg jobbet selvstendig fra første dag og fikk ansvar for flere av byråets største kunder.

Erfaring og kompetanse:

  • Produserte ca. 150–200 annonser i uken i flere formater
  • Design tilpasset ulike målgrupper, merkevarer og budskap
  • Selvstendig arbeid med kunder og leveranser
  • Effektivisering av arbeidsflyt og repetitive oppgaver
  • Erfaring med AI-verktøy i designprosessen
  • Innsikt i reklame, e-commerce og hva som får en annonse til å fungere

UX / effektivisering:

Jeg utviklet en Figma-plugin for å automatisere repetitive oppgaver som filnavn og kopiering av tekst og bilder. Jeg bidro også til å forbedre AI-prompts og arbeidsflyt.

NETTSIDE DESIGN : CloudChase

HTML - Python - CSS - Adobe Programmer

Eget Prosjekt:

Eget fullstack-prosjekt som kombinerer design, frontend og AI. Brukeren kan utforske skytyper og laste opp bilder for AI-basert klassifisering av skyer. CloudChase lar brukeren bla gjennom og lære om ulike skytyper, strukturert etter høyde og kategori. Hver skytype har en egen detaljside med fordypende informasjon.

Erfaring og kompetanse:

  • Eget fullstack-prosjekt
  • UI og frontend-utvikling
  • HTML / CSS
  • Backend med Python og Flask
  • Integrasjon av AI-basert bildeanalyse
  • Strukturering av prosjekt for videre utvikling
  • Kombinasjon av design og programmering
